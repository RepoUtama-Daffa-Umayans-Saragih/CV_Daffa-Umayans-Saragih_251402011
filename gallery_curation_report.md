## 🎯 Executive Summary of Curation Strategy

To prevent visual clutter, network payload exhaustion, and GPU frame drops during CSS marquee animation, the asset library was curated from 30+ files down to **18 high-impact media items** (exactly **3 items per folder/category**). 

Each selected item satisfies three criteria:
1. **Compositional Quality:** Strong focal point, clear lighting, and professional framing.
2. **Narrative Value:** Demonstrates real student and professional leadership (Data Science victory, UI/UX design, C++ teaching, competitive chess, and university organization).
3. **Bento Grid Variety:** Mix of aspect ratio classes (`bento-card--wide`, `bento-card--tall`, `bento-card--square`) and media types (high-res images + 1 embedded autoplay video) to create an organic, modern Bento Box rhythm.
